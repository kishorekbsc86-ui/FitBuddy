# Brainstorming & Ideation Phase

## Project idea

FitBuddy is an AI-assisted fitness-plan generator. A user enters basic fitness information and receives a personalised seven-day workout plan and a nutrition or recovery tip.

## Problem statement

People often struggle to turn broad goals such as weight loss, muscle gain, wellness, flexibility, or endurance into a clear and sustainable routine. Generic plans do not adapt to individual preferences or feedback.

## Proposed solution

FitBuddy uses Google Gemini to create structured workout guidance, save the result, and revise it when the user submits feedback. A browser interface makes the process accessible without API knowledge.

## Core ideas selected

- Personal profile form with goal and intensity
- Seven-day workout plan
- Goal-aware nutrition or recovery tip
- Feedback-based plan revision
- Coach dashboard for saved plans
- JSON API for future integrations

## Target users

- Individuals starting or maintaining a fitness routine
- Coaches who need a simple view of multiple client plans
- Students learning FastAPI, database persistence, and generative AI integration
